# 14 — V3.5 Rectangular Testing Variant

> **Status:** Test-only developer build  
> **Date:** 2026-06-26  
> **Author:** AeroCool Engineering  
> **Note:** This is NOT the general product design. The hexagonal V3 tile remains the standard.

---

## What This Is

The V3.5 is a **rectangular testing variant** of the AeroCool Flat model. It exists solely to make rapid prototype testing easier in standard rectangular window frames and sliding door gaps. The general product — the hexagonal V3 tile — is designed for modularity, custom window sizing, and the maker network. The V3.5 is a convenience build for the developer.

---

## Why a Rectangle?

### The Hexagon Problem

Hexagonal tiles are elegant for modularity:
- They tile in a honeycomb pattern
- They can be snapped together to fit any window size
- They distribute funnels evenly across the area

But they do not fit cleanly into **rectangular openings**. When you place hex tiles in a rectangular window frame, you get:
- Small triangular gaps at the corners and edges
- Light and air bypass around the tile edges
- A need for additional weatherstripping or foam to seal the gaps
- Extra print time and material spent on hex geometry that gets cut off by the frame

For a commercial product sold to end users with varying window sizes, this is acceptable — the tiles are modular and the gaps are filled with compressible gasket. For a developer doing rapid testing, it is a nuisance.

### The Rectangle Solution

A rectangular tile:
- Butts edge-to-edge with zero gaps in a rectangular frame
- Fills the opening completely without corner gaps
- Is faster to design (no hexagonal geometry)
- Is easier to seal with standard foam weatherstrip
- Can be taped or clamped into a window frame for quick testing

The trade-off is that rectangles do not scale to arbitrary window sizes the way hexagons do. A 100×150mm rectangle fits one window. A 100mm hex tile fits any window when you add more tiles. This is why the rectangle is test-only.

## Geometry Details

### Base Tile V3.5

- **Outer dimensions:** 100mm (width) × 150mm (length) × 25mm (thickness)
- **Chamber recess:** 90mm × 140mm × 5mm deep (1mm clearance from edges for insert fit)
- **Funnel layout:** 7 funnels in a staggered 2-row grid
  - Top row: 3 funnels at y = +17.5mm, x = -30mm, 0, +30mm
  - Bottom row: 4 funnels at y = -17.5mm, x = -45mm, -15mm, +15mm, +45mm
- **Funnel geometry:** Same as V3 — 15mm inlet → 4mm throat → ~10mm outlet at 24° cone angle
- **Fill port:** 3mm diameter vertical bore, centered on the top edge, 2mm inset from the outer edge

### Baffle Insert V3.5

- **Outer dimensions:** 89mm × 139mm × 2mm (base plate)
- **Fin dimensions:** 3 fins, each 125mm long × 1.5mm thick × 3mm tall
- **Fin angle:** 20° to the airflow direction (same as V3)
- **Fin spacing:** 18mm center-to-center (offsets at -18mm, 0, +18mm from center)
- **Fins span the LENGTH direction** (along the 150mm axis), perpendicular to the airflow
- **Fuzzy skin:** Required slicer setting (same as V3)
- **Layer line orientation:** Printed flat on bed → horizontal layer lines → cross-flow roughness when installed
- **Fill port hole:** 3mm diameter, aligned with base tile fill port

## Print Instructions

### Base Tile V3.5

```
Material: PETG
Nozzle: 0.4mm standard
Layer height: 0.2mm
Infill: 15-20% (structural ribs only)
Print orientation: Outside face DOWN on bed (funnels vertical)
Supports: NONE
Bed adhesion: BRIM recommended (PETG warping)
Print temperature: 230-250°C
Bed temperature: 70-80°C
Estimated time: ~3 hours
Estimated filament: ~60g
```

**Important:** The 150mm length may exceed the bed size of some printers (e.g., Ender 3 bed is 235mm × 235mm, so 150mm fits comfortably). Check your bed dimensions before printing.

### Baffle Insert V3.5

```
Material: PETG
Nozzle: 0.4mm standard
Layer height: 0.2mm
Infill: 15-20%
Print orientation: Flat on bed (layer lines horizontal)
Fuzzy skin: ENABLED (thickness 0.3-0.5mm, density 1.0-2.0)
Supports: NONE
Bed adhesion: Brim recommended
Estimated time: ~25-35 minutes
Estimated filament: ~12g
```

## Testing Protocol for V3.5

The V3.5 follows the same validation protocol as the V3 (see [Flat Evaporative System](12-flat-model-evaporative-system.md)), with the addition of:

### Window Frame Fit Test

1. Measure your window opening or sliding door gap
2. If the 100×150mm tile fits: tape or clamp it into the frame with foam weatherstrip on the edges
3. If the tile is too small: butt multiple tiles edge-to-edge (they should seal with no gaps)
4. If the tile is too large: the SCAD file is parametric — adjust TILE_WIDTH and TILE_LENGTH, re-render
5. **Check:** No air bypass around the edges. The rectangle should fill the frame completely.

### Edge-to-Edge Sealing

- Two V3.5 tiles butted together: no gap, no light leak
- Seal the perimeter with 5mm foam weatherstrip tape
- Optional: small bead of silicone or tape along the butt joint for air-tightness
- The rectangular shape makes this trivial compared to hex tile gap-filling

### Rapid Swap Test

The V3.5 is designed for quick iteration:
- Print one base tile and 2–3 baffle inserts
- Test insert A (fuzzy skin, high density)
- Swap to insert B (fuzzy skin, low density)
- Swap to insert C (smooth, no fuzzy skin — control test)
- All inserts fit the same base tile. No need to reprint the base.

## When to Use V3.5 vs. V3

### Use V3.5 (Rectangle) when:

- You are doing **rapid prototype testing** in your own window
- You want **edge-to-edge sealing** with no gaps
- You are testing **baffle fin variations** and need quick insert swaps
- You have a **standard rectangular window frame** (most common)
- You want to **test the vibe** before committing to a full hex tile array

### Use V3 (Hexagon) when:

- You are building the **general product** for distribution
- The user has an **arbitrary window size** that doesn't match a standard rectangle
- You need **modularity** — the user buys 3 tiles, 6 tiles, or 12 tiles to fit their window
- You are **selling to the maker network** — hex tiles are the standard product
- You are **documenting the final design** — the hex tile is the canonical AeroCool form

## Design Note: The V3.5 Is Not a Fork

The V3.5 is not a competing design to the V3. It is the **same design in a different shape**. The physics, the funnel geometry, the baffle cascade, and the fuzzy skin strategy are identical. The only difference is the outer perimeter.

This means:
- Test data from V3.5 is **directly applicable** to V3. A 4°C drop in the rectangle means a 4°C drop in the hex tile.
- The baffle insert geometry is **analogous** — 3 fins, same angle, same height, same thickness. The only difference is the outer boundary of the base plate.
- If you optimize the fin angle, fin spacing, or fuzzy skin settings on the V3.5, those optimizations **transfer directly** to the V3.
- The V3.5 is a **testbed**, not a product. When testing is complete, the lessons learned are applied to the hex V3 for the general release.

## Future of the V3.5

The V3.5 will likely be **deprecated** once the V3 hex tile is validated. It may remain in the repo as:
- A reference for how to make test variants of the general design
- A starting point for users who want to create custom-size rectangular panels for their specific windows
- A teaching example for how to modify the parametric SCAD files

It will not be sold, marketed, or distributed as a product. The hexagonal V3 is the AeroCool Flat model. The V3.5 is a developer tool.
