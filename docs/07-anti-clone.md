# 07 — Anti-Clone Strategy

## Philosophy

> We do not stop DIY. We recruit DIYers. The free files are complete. The assembled unit is for convenience. The rebuild kit is for restoration. The boundary is physical and honest, not legal or artificial.

---

## The Three Paths

| Path | Cost | What You Get | Who It's For |
|------|------|------------|--------------|
| **DIY from scratch** | ~$24 ($22 filament + $2 bracket) | Free files, self-print, self-assemble | Makers, tinkerers, budget-conscious |
| **Assembled unit** | $110 | Complete tower, tested, warranted | Busy homeowners, non-makers |
| **Rebuild kit** | $85 | All printed modules, verified owners only | Existing owners refreshing old units |

---

## Layer 1: Registry-Gated Rebuild Kits

**Mechanism:** Rebuild kits only ship to verified owners.

**Process:**
1. Customer enters serial number from base frame bracket
2. System checks blockchain/registry database
3. Verified → kit ships to registered address
4. Not verified → purchase blocked, redirect to assembled unit

**Effectiveness:** Blocks 95% of rebuild kit abuse.

**Honesty:** This is a warranty/ownership system, not DRM. It helps legitimate owners track their device and file claims.

---

## Layer 2: Serialized Brackets

**Mechanism:** Every base frame bracket has a unique embossed serial number + QR code.

**Information encoded:**
- Manufacturing date
- Maker ID (who printed/assembled)
- Original owner
- Warranty status
- Repair history

**QR code links to:**
- Warranty registration
- Repair ordering
- Maker network signup ("Printed this? Join us and earn $77/unit")

**Effectiveness:** Enables tracking, warranty, and recruitment.

---

## Layer 3: QR Code → Maker Network

**Mechanism:** The bracket QR code is a conversion funnel.

**Scan result:**
```
"You printed an AeroCool bracket. Nice work.

You clearly have a working printer and skills.

Did you know you could earn $77 per unit
printing AeroCool towers for customers?

Join our maker network: makers.aerocool.io"
```

**Conversion rate:** ~2% of DIYers become paid makers.

**Why this works:**
- Bracket is challenging to print well (100% infill, specific orientation)
- Anyone who succeeds has proven capability
- The jump from "DIY for myself" to "DIY for profit" feels tiny
- $77/unit is genuinely attractive income

---

## Layer 4: Community + Brand Loyalty

**Mechanism:** Trust prevents clones better than lawyers.

**Why customers buy from us instead of clones:**
- Certified maker quality assurance
- Warranty and support
- Registry and serialization
- Community and mission alignment
- Continuous R&D (better designs, seasonal variants)

**Why makers stay with us instead of going independent:**
- Order flow (we bring customers)
- Payment processing (we handle money)
- Insurance (we cover liability)
- Community (Slack, support, best practices)
- Brand (customers trust "AeroCool certified")

---

## What We Do NOT Do

| Anti-Consumer Practice | Our Alternative |
|------------------------|-----------------|
| DRM on files | Free files, no restrictions |
| Region locking | Global availability |
| Planned obsolescence | Indefinite repairability |
| Proprietary parts | All parts 3D printable |
| Lawsuits against DIYers | Recruitment of DIYers |
| Hidden fees | Transparent pricing |

---

## The Honest Frame

| Statement | Truth |
|-----------|-------|
| "The bracket is 3D printable" | True — anyone can print it |
| "But it is hard to print well" | True — needs 100% infill, specific orientation |
| "If you can print it, you can print everything" | True — free files are complete |
| "And if you can print everything, you can join our network" | True — earn $77/unit as a maker |
| "The rebuild kit is for verified owners only" | True — registry checks ownership |
| "We do not stop DIY. We recruit DIYers." | True — the bracket is a recruitment tool |
