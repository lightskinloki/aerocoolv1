# 08 — 12-Month Roadmap

## Phase 1: Proof of Concept (Months 1–3)
**Budget: $80 | Time: 90 hours**

| Month | Goal | Tasks | Success Metric |
|-------|------|-------|----------------|
| 1 | Design first funnel | Learn Fusion 360/Blender, model Venturi funnel, print in PETG, test with desk fan | Measurable temperature drop (even 1°C) |
| 2 | Print first stage | Design 7-funnel array, test airflow, design base/cap/panels | Stage moves air, no leaks, structurally sound |
| 3 | Stack 3 stages + measure stack effect | Stack vertically, test with heat lamp, add water channels, measure cooling | 5°C+ drop with water, 2°C+ without, stack effect works |

**Decision Gate:** If Month 3 prototype fails, kill the project. If it works, commit to Phase 2.

---

## Phase 2: Prototype Refinement (Months 4–6)
**Budget: $270 | Time: 120 hours**

| Month | Goal | Tasks | Success Metric |
|-------|------|-------|----------------|
| 4 | Print 3 complete towers | 6 stages + base + cap + water + panels, iterate geometry | 3 working towers ready for testing |
| 5 | Real-world testing | Ship to AZ (dry), IL (moderate), FL (humid), collect 2-week temp logs | Performance data across 3 climates |
| 6 | Design refinement | Incorporate feedback, finalize CAD, create assembly instructions, print profiles | Finalized design files + documentation |

## Contingency Plans

| Risk | Mitigation |
|------|------------|
| PETG warps after 200 heat cycles | Switch to ASA/ABS for hot climates; design heat shields |
| Maker ships defective unit | Quality audit process; insurance coverage; maker retraining |
| Competitor patents first | File provisional patent Month 7; prior art documentation |
| 3D printing regulated | Compliance with fire codes; UL listing if required; lobbying via maker community |
| Maker network collapses | Redundancy (multiple makers per region); company-operated backup printer farm |
| Customer injury from tipping | Mandatory mounting bracket; installation instructions; liability insurance |
| Free files cannibalize sales | Bracket recruitment funnel; brand loyalty; convenience premium |
